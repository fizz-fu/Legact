# RPPS-1600压力分布测量系统

## 产品简介

RPPS-1600是一款40×40点压力分布测量系统，共1600个感应点。

## 主要参数

| 项目 | 参数 |
|---|---|
| 阵列规格 | 40×40 |
| 感应点数量 | 1600点 |
| USB帧率 | 60 fps |
| UART帧率 | 3 fps |
| 感应区域 | 90 × 83.6 mm |
